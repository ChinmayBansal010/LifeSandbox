# Workflow, tools and skills

LangGraph is the primary runtime. Its typed `ConversationState` moves from intent and skill selection to an LLM supervisor agent. The agent receives the conversation history, relevant skill instructions and an intent-scoped tool catalog. It can request a tool call; LangGraph executes only registered local tools, appends their result, and returns control to the LLM for the user-facing response. The loop is bounded to two tool rounds. Task and reminder reads are read-only; writes are limited to the authenticated user and run in the chat database transaction. Reminder tools require a timezone-aware schedule, and the prompt instructs the model to ask when timing is ambiguous. The LLM, rather than application code, interprets the user's request and makes recommendations.

Skills are a code-owned allowlist with descriptions, applicability keywords and instructions. Selection is deterministic; user/document text cannot register code or expand permissions. The current six skills are budgeting, career, education, purchasing, travel and time management. The `compare_allocations` tool adds up categories supplied by the LLM and checks them against an available total; it does not choose a winner or write advice. Browser Use is optional per message: the UI must grant browser access for the exchange and configuration must be enabled. It uses a local browser session to open GitHub search and repository pages and read visible page text before the chat model writes the answer. Page content is untrusted.

Research is not yet wired into the chat tool loop; it remains available through the separate research API when configured. No external NeMo Agent Toolkit integration or harness comparison is implemented. LangGraph state checkpointing and interrupted run resume remain unfinished.
