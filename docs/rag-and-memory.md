# RAG, documents and memory

Hash embeddings and chunking utilities provide deterministic local experiments; they are not semantic production embeddings. Retrieval filters owner before ranking and returns no irrelevant filler. No pgvector schema/index or persistent vector repository exists yet, and uploaded document extraction is not enabled. Neon Object Storage upload URL generation is available when configured; file completion explicitly reports the unprocessed state.

Structured memories include owner, category, source, lifecycle status, timestamps, confidence, optional source conversation and optional project link. Only explicit chat requests containing "remember" are considered for storage. A user's `auto_categories` policy can auto-save only explicit nonsensitive categories; otherwise the request is stored as a pending candidate for review. Sensitive categories are never auto-saved, and credential-like content is rejected before candidate storage. Candidate approval is explicit. Matching preference subjects use deterministic identity keys so a corrected fact supersedes the older active value. Retention archives expired active memories during retrieval.

Approved SQL memories are retrieved across conversations by lexical token overlap and freshness, limited to five, and supplied as untrusted factual context. The chat also searches up to the latest 1,000 user messages in the owner's other conversations, retrieves matching user/assistant turns, and supplies a few excerpts as local conversation context. This transcript recall uses the local SQL database and does not require Mem0. It follows the same local-memory policy switch and excludes other users' conversations. Retrieval is lexical rather than semantic, so exact names, topics, and distinctive terms work best; broad requests such as "what did we talk about last time?" fall back to recent turns. Mem0 remains optional and is contacted only when the user opts into that exchange and `hosted_memory_allowed=true` is enabled in their policy. Provider failure is isolated from local memory and chat persistence.
