# RAG, documents and memory

Hash embeddings and chunking utilities provide deterministic local experiments; they are not semantic production embeddings. Retrieval filters owner before ranking and returns no irrelevant filler. No pgvector schema/index or persistent vector repository exists yet, and uploaded document extraction is not enabled. Neon Object Storage upload URL generation is available when configured; file completion explicitly reports the unprocessed state.

Structured memories require explicit user consent and include owner, category, source, lifecycle status, timestamps, confidence and optional source conversation. Active local memories are ranked by token overlap and freshness, limited to five, and supplied to chat as untrusted factual context. A user-scoped policy controls memory enablement, category lists, retention and hosted-provider permission. Mem0 requires both per-exchange opt-in and `hosted_memory_allowed=true`. Automatic candidate extraction and review are not implemented; hash embeddings remain experimental and recall is lexical rather than semantic.
