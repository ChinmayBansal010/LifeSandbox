# RAG, documents and memory

Hash embeddings and chunking utilities provide deterministic local experiments; they are not semantic production embeddings. Retrieval filters owner before ranking and returns no irrelevant filler. No pgvector schema/index or persistent vector repository exists yet, and uploaded document extraction is not enabled. Neon Object Storage upload URL generation is available when configured; file completion explicitly reports the unprocessed state.

The app's structured memory records remain user-entered with explicit consent, ownership, category, source and timestamp. The optional Mem0 Platform integration adds semantic long-term recall to chat: when the user checks “Use Mem0 hosted memory for this exchange,” the current message is sent to Mem0 for search and, after a successful reply, the user/assistant exchange is submitted for memory extraction. Unchecked messages are neither searched nor saved through Mem0. Configure `MEM0_API_KEY` and optionally `MEM0_HOST` to enable it. Without a key, the feature stays disabled and the local app continues to work. Mem0 queries and opted-in exchanges are processed by the configured Mem0 host, so use this setting only when that data flow is acceptable.
